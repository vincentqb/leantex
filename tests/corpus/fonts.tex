\section{Faces}

Body text is set in the serif family. \textbf{This clause is bold} and
\textit{this clause is italic}, while \textbf{\textit{this one is both}}.
Inline \texttt{monospaced code} switches family, and {\sffamily a sans run}
does too.

\begin{itemize}
  \item \textbf{Bold label} followed by ordinary text.
  \item \emph{Emphasis} toggles italic, so \emph{nested \emph{emphasis}}
  returns upright.
\end{itemize}
