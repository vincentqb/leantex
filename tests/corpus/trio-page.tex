\section{Cardamom Press}

Cardamom Press is an invented letterpress studio that exists to give this
corpus a subject. Its design is declared once — a palette, a rhythm, an
element style — and this page, the deck beside it, and the card beside
that all read the same declarations.

\section{Practice}

\begin{itemize}
  \item Wood type and photopolymer plates; \primary{amber} is the one accent.
  \item Editions of \texttt{64} or fewer, numbered by hand.

\end{itemize}
