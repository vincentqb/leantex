# A ( standing where a path operation would begin starts a new subpath, so
# one \path or \draw statement may carry several of them and the statement's
# option bracket rides on each (Picture.subpaths).
# A node body is read for what it says: \\ opens a real second line (one
# label shape per line), a size switch opening a line sets that line's size,
# \textcolor sets its body in the named role, and a phantom inks nothing and
# names nothing. A construct the subset cannot draw drops its own spelling,
# keeps what its content groups say, and is named (W0334) -- the label
# degrades to its text, never to nothing (Picture.labelFloor_accounts). A
# size switch standing inside a line is the refusal row: one label shape
# carries one size.
# \tikzexternalize and \pictures{ tool = lualatex } both pin the tool the
# boundary is already open with, so they move no ink (inert:default); the
# declared refusal tool = none is the row that changes the document.
# A \tikzset key list that is not a definition, and a picture's own bracket,
# both carry the keys the subset reads into every statement below them, the
# statement's own bracket winning (Picture.mergeOpts, four levels:
# document < picture < every X < own). An arrow-tip default declared once in
# the preamble is the motivating one -- pgf's -Latex is arrows.meta's
# spelling of pgflibraryarrows' latex tip, one shape under two names, so both
# draw this subset's head. A key no statement reads stays W0334 at the line
# that wrote it, so these rows are impl for the command while the key-level
# facts are witnessed in Tests/Surface.lean's pictureGlobalKeyChecks (a
# per-row preamble cannot spell them).
