# source: the cleveref manual (v0.21.4, 2018/03/27), §2 "Typesetting
# Cross-References" for the reference commands and §8 "Customising the
# Reference Format" for the configuration commands. The implemented forms
# resolve through the label table with the kind's locale name
# (Ir.refText; names from the package's own language blocks under its
# default options). Recorded gaps, pinned below where a row can spell
# them: a comma list is read as one unknown key (W0349 names it); the
# page-reference family needs page numbers at resolution, which the
# single-pass table does not carry; \label's optional [type] argument is
# not scanned (E0304 where it stands); the format/name configuration
# commands would override locale data the engine owns, refused by name.
