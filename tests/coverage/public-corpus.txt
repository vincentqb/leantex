# The declared public corpus the blocker ranking reads: documents the TeX
# distribution itself ships, as paths relative to its root
# (`kpsewhich -var-value TEXMFDIST`). `blockers --rank` resolves each entry
# inside that root, following symlinks, and refuses one that leaves it, so
# this file can only ever name the distribution's own files. One document
# per entry: an entry is a content-distinct document, and the ranking keys
# documents by content, so a second path to the same bytes counts once.
# Provenance: the 45 content-distinct documents that built with lualatex
# -halt-on-error -interaction=nonstopmode (TeX Live 2026) out of a screen of
# 111 candidates taken from the distribution on 2026-09-25; the candidate
# selection was not recorded. 31 of the 45 are one package's pictures
# (tex/latex/ghsystem/pictures), so the corpus is narrow and the ranking
# reads as a smoke test of the method, not as a survey of LaTeX in use.
