# The declared public corpus the blocker ranking reads: single-file documents
# the TeX distribution itself ships, as paths relative to its root. A line is
# `<sha256>  <path>`, the format `sha256sum` writes, so an entry is made, and
# checked, by one command run from the root:
#   cd "$(env -i PATH="$PATH" kpsewhich -var-value TEXMFDIST)" && sha256sum <path>
# `blockers --rank` asks kpsewhich for that root with only PATH set, resolves
# each entry inside it following symlinks, and refuses one that leaves it or
# whose bytes are not the ones its pin names, so this file can only name the
# distribution's own files as they were when declared, whatever redirects
# kpsewhich. Single-file: the screen builds a copy of each document alone, so
# a document that inputs a sibling file reads as one that does not build and
# is not here. One document per entry: an entry is a content-distinct
# document, and the ranking keys documents by content, so a second path to
# the same bytes counts once.
# Provenance: the 45 content-distinct documents that built with lualatex
# -halt-on-error -interaction=nonstopmode (TeX Live 2026) out of a screen of
# 111 candidates taken from the distribution on 2026-09-25; the candidate
# selection was not recorded. 31 of the 45 are one package's pictures
# (tex/latex/ghsystem/pictures), so the corpus is narrow and the ranking
# reads as a smoke test of the method, not as a survey of LaTeX in use. The
# pins were taken with the command above on 2026-09-26.
