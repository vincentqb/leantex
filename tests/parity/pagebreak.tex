% parity: two pages with the break declared rather than computed, which separates the page-count level from either engine's page-breaking policy
% Floor probe. The point of declaring the break is that the page-count level
% then tests the count and nothing else: a fixture whose pages are filled
% until they overflow would fail P1 for a difference in breaking policy and
% say nothing about whether the two engines agree on how many pages a
% document has.
%
% Micro-typography is left at the engine's default, protrusion and
% expansion on, although the reference loads no microtype. Measured
% 2026-09-25: declared off, the engine hyphenates "believed" at the end of
% page 2's first line where the reference does not, and this fixture stops
% at P2 instead of P4. So the P4 recorded for it holds only with expansion
% on, and declaring it off is a fall of this floor, a human's to accept.
\documentclass{article}
\page{ size = letter, margin = 1in, fontsize = 10pt, measure = free }
\fonts{ body = "Open Sans" }
\begin{document}
The first sheet carries the summary. Two ledgers, one clerk, and a standing
disagreement that resolves itself every afternoon without anyone
intervening.

\newpage

The second sheet carries the detail, which nobody reads. It is kept because
the summary is only believed by people who know the detail exists.
\end{document}
