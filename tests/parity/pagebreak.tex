% parity: two pages with the break declared rather than computed, which separates the page-count level from either engine's page-breaking policy
% The point of declaring the break is that the page-count level then tests
% the count and nothing else: a fixture whose pages are filled until they
% overflow would fail P1 for a difference in breaking policy and say
% nothing about whether the two engines agree on how many pages a document
% has.
%
% The pairing is not yet declared alike on two axes. The engine keeps its
% default micro-typography, protrusion and expansion on, although the
% reference loads no microtype. The reference keeps LaTeX's default
% sentence spacing, \nonfrenchspacing, while the engine sets every
% interword space alike. Measured 2026-09-26, one variable at a time:
% engine micro-typography off stops this fixture at P2, because the engine
% then hyphenates "be-lieved" on page 2's first line. The reference
% declaring \frenchspacing also stops it at P2, because the reference then
% hyphenates the same word. Both changes together reach the top. Which way
% the pairing is made alike is a human's decision, and until then the
% fixture stays at P4.
\documentclass{article}
\page{ size = letter, margin = 1in, fontsize = 10pt, measure = free }
\fonts{ body = "Open Sans" }
\begin{document}
The first sheet carries the summary. Two ledgers, one clerk, and a standing
disagreement that resolves itself every afternoon without anyone
intervening.

\newpage

The second sheet carries the detail, which nobody reads. It is kept because
the summary is only believed by people who know the detail exists.
\end{document}
